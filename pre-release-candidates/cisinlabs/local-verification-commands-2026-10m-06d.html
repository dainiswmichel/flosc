WordPress source

The image wordpress:php8.3-apache supplies PHP 8.3 and Apache. command is apache2-foreground. That image is not the WordPress source. /opt/flosc-wp-v111/install-wordpress-org.sh runs when /var/www/html/index.php or /var/www/html/wp-includes/version.php is absent. It reads https://api.wordpress.org/core/version-check/1.7/, downloads https://wordpress.org/wordpress-<version>.tar.gz, and checks https://wordpress.org/wordpress-<version>.tar.gz.sha1 before extracting. An existing volume is left as installed. The image Dockerfile downloads from the same host, https://wordpress.org/wordpress-$version.tar.gz, at image build. The pin wordpress:7.1.1-php8.3-apache is that script with version='7.1.1'.

The CLI service is wordpress:cli-php8.3 with user: "33:33", the same uid as Apache www-data. The CLI image’s own default user is uid 82. Files created as uid 82 are not writable by Apache, and a dashboard core update then fails with mkdir_failed_ziparchive on wp-content/upgrade.

Posts, flow options, and installed starter-pack content go with those volumes. 21. Local Playground of the zip from the local tree

This command unpacks zip-files/flosc.zip, the archive built from the local tree, and mounts that directory into one new local Playground. The blueprint installs Plugin Check from wordpress.org and activates it, then runs wp plugin check flosc. The command does not call testing-bench.sh. The Playground address is the URL printed when the process starts. That process is local. The standing burn site is http://[burner-host]/.

bash << 'EOS'
set -u
REPO="$HOME/2026/flosc_project_folder/mvp_sprint/flosc_8_0_0/flosc"
SOURCE="$HOME/2026/flosc_project_folder/mvp_sprint/flosc_8_0_0/flosc"
ZIP="$(cd "$SOURCE/../../.." && pwd)/zip-files/flosc.zip"
FLOSC_ZIP_OUT_DIR="$HOME/2026/flosc_project_folder/zip-files" "$SOURCE/build-dist-zip.sh"
echo "ZIP=$ZIP"
UNPACK="/tmp/flosc-verify-playground"
BLUEPRINT="/tmp/flosc-verify-pc-blueprint.json"
ITERATION="$(sed -n 's/^ \* Internal Iteration: //p' "$SOURCE/flosc.php" | head -1)"
case "$ITERATION" in
  v[0-9]*) REPORTS="$HOME/Desktop/flosc-${ITERATION}-verify" ;;
  *) REPORTS="$HOME/Desktop/flosc-verify-$(date -u '+%Yy-%mm-%dd-UTC-%Hh-%Mm-%Ss')" ;;
esac
mkdir -p "$REPORTS"
rm -rf "$UNPACK"
mkdir -p "$UNPACK"
unzip -q "$ZIP" -d "$UNPACK"
cat > "$BLUEPRINT" << 'EOB'
{
  "$schema": "https://playground.wordpress.net/blueprint-schema.json",
  "login": true,
  "steps": [
    { "step": "installPlugin",
      "pluginData": { "resource": "wordpress.org/plugins", "slug": "plugin-check" },
      "options": { "activate": true } },
    { "step": "wp-cli", "command": "wp plugin check flosc --format=csv" }
  ]
}
EOB
{
  echo "========== 21. PLAYGROUND =========="
  echo "zip under test: $ZIP"
  shasum -a 256 "$ZIP"
  echo "mount: $UNPACK/flosc"
  echo "tests directories: $(find "$UNPACK/flosc" -type d -name tests | wc -l | tr -d ' ')"
  echo "build-dist-zip.sh files: $(find "$UNPACK/flosc" -name build-dist-zip.sh | wc -l | tr -d ' ')"
  npx --yes @wp-playground/cli@latest run-blueprint \
    --blueprint="$BLUEPRINT" \
    --mount="$UNPACK/flosc:/wordpress/wp-content/plugins/flosc" \
    --php=8.3
  echo "playground exit: $?"
} | tee "$REPORTS/21-playground.txt"
EOS

# FLOSC Personality Archetypes — source references

Reference documentation for the archetypes offered by the DA1 AI Personality Builder.

These are **bibliographic citations**, not services FLOSC contacts. The plugin never
requests any of these addresses: no `wp_remote_*` call, no `fetch`, no embed. They are
listed here so an author can read the source material an archetype draws on, and so the
attribution stays with the character description it belongs to.

They were previously carried as `links:` arrays inside
`assets/js/flosc-personality-builder.js`. They are no longer in the shipped plugin: a URL
in plugin code reads as an external-service dependency to a reviewer, and a citation is not
a dependency. The archetype's `works` list — the titles — remains in the builder, so the
scholarly grounding is still visible to the author while the addresses live here.

## Why these are not external services

The WordPress.org guideline covers services a plugin *reaches out to* — anything that
transmits or receives data. Every address above is inert reference text. Nothing in FLOSC
loads, embeds, pings or posts to any of them, and no user data travels to any of them.

The external services FLOSC genuinely contacts — the AI providers, the payment
processors, the speech services — are disclosed in `readme.txt` under
`== External Services ==`, each with what is sent, when, and links to that service's
terms and privacy policy.
